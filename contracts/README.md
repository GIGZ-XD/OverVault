# contracts (owner: Ganesh)

Four contracts deployed to **MST Testnet** and verified on **MSTScan**:

1. Ownership Verification  (`src/ownership.spec.md`)
2. Permission Management   (`src/permission.spec.md`)
3. Integrity Verification  (`src/integrity.spec.md`)
4. Audit Verification      (`src/audit.spec.md`)

Write the contract sources in `src/` using the language/toolchain from docs.mstblockchain.com
(the spec files describe what each must store and emit). Put tests in `tests/`, deploy scripts in
`scripts/`, and record every deployment in `deployed.testnet.json`, the single source of truth
for addresses and ABIs.
